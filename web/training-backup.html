Save the old tablet's training records

A one-time bookmark that copies the old training app's records off the tablet into a file (cdg-training-backup.json). It only reads — it doesn't change anything on the old app.

On the iPad (Safari)

  1. Tap Copy the bookmark code below.
  2. Tap the Share button → Add Bookmark. Name it Save training backup → Save.
  3. Open Bookmarks → Edit → tap Save training backup. Delete the address and paste the code. Tap Done.
  4. Open the old training app and wait until it has loaded (and synced, if it's signed in to Microsoft).
  5. Open Bookmarks → tap Save training backup. Safari saves cdg-training-backup.json to Downloads.
  6. Get the file to the PC (AirDrop, OneDrive, or email it to yourself), then: CDG Ops → Admin → 🎓 Training setup → Load the backup file.
  7. After the counts are checked and saved, delete the file from the iPad and the PC — it holds the trainers' PINs.

On a computer

Drag this button to the bookmarks bar, open the old training app, then click the bookmark.
